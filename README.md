## Entry

> The doormat gets stepped on by everyone, thanked by no one, and still says 'welcome'.

A one-line review of the dullest everyday object I could name: the doormat.
It is stepped on daily, never thanked, and still greets you with "welcome" —
the joke comes from how the object really behaves.
